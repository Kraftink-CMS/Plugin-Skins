Après avoir lié un compte Minecraft Java vérifié, les membres peuvent importer et prévisualiser leurs textures avant de les enregistrer.

- Les lanceurs compatibles peuvent consulter et envoyer des textures via l’API.
- Activez les liens PNG publics si vous souhaitez permettre le partage des nouveaux fichiers.
- Appliquez les skins en jeu avec KraftLink et SkinsRestorer sur un serveur compatible Bukkit. Les fichiers de cape sont utilisables sur le site et dans les lanceurs compatibles.

Dans **Extensions → Skins et capes**, choisissez qui peut importer des textures et quels serveurs connectés peuvent les appliquer.
